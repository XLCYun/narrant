# 审核工具栏图标操作

## 已确认需求

- 检查更新、双栏切换、退出审核均使用等大的圆形图标按钮，悬停显示提示，并提供可访问名称。
- 检查更新：用户点击后先检查当前 Review Selection；有更新则直接刷新审核，不再要求第二次点击。检查期间和刷新期间禁用重复操作。
- 无更新、更新成功和错误使用现有通知。移除工具栏常驻更新状态文字。
- 打开、切换或恢复审核时不自动检查更新；切换失败也不自动重启已取消的检查。用户点击工具栏后才检查，离开审核后忽略迟到检查结果。保留版本再次变化时的校验与重试提示。
- 双栏按钮始终显示双栏图标；双栏开启时绿色底、白色图标，关闭时使用普通 outline 样式。窄窗口维持单栏并禁用双栏按钮。
- 退出按钮仅改变呈现，保留关闭审核的原有生命周期。宝宝模式不在本次修改范围。

## 验收

- 通过 Reader 与 lifecycle 现有公开接口验证单击刷新、无更新、失败、取消及重复操作。
- Preview Harness 覆盖宽窄窗口、长短内容、双栏开关、提示展开与更新忙碌状态。
- 执行类型检查、前端测试、Lint 和生产构建；不手动触发 quality-gate。

## 宝宝模式圆形按钮（2026-09-05 最终方案）

- 宝宝模式与更多菜单移入顶部审核工具栏，仅文件改动视图有可用文件时显示，文件标题行不再承载操作。
- 宝宝模式使用 32px 圆形按钮，恢复现有宝宝 emoji 资产；关闭为普通 outline，开启使用与双栏按钮完全一致的实心主题 primary。保留可访问名称、pressed、busy 和提示。
- 顶部顺序：检查更新、双栏、宝宝模式、更多选项、退出。更多选项在宝宝模式开启和关闭时均显示；重新生成只在宝宝模式开启、已完成且范围可用时可执行。
- 生成中仍允许关闭并取消生成；失败恢复沿用底部重试入口。
- 应用内浏览器已验证 1440×900 与 800×700、菜单展开及开启状态的主色一致性，验收后恢复默认 viewport。
