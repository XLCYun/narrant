# 直接调用独立语言分析器

2026-10-22 补充：[ADR-0039](0039-implement-codegraph-protocol-in-native-analyzers.md)
进一步限定公共协议必须由语言程序自身实现，替代本文允许跨语言共享宿主的内部实现边界。
本文的调用方安装调度、独立分发及文件选集决定继续有效。

CodeGraph 主要维护各语言的源码分析能力，每个语言分析器应成为能独立接收项目输入、
直接返回 Code Graph 的产品。2026-10-21 用户确认：在同一个 CodeGraph 仓库维护统一
stdio JSON 契约与 `analyzers/`，各分析器分别构建打包；允许直接入口携带运行时与依赖。
共享图验证和生命周期实现可以复用，消费者不需要总 CLI、私有协议或语言运行时命令。

Narrant 等调用方负责下载、管理精确版本、按语言调用和合图。CodeGraph 负责分析器的
构建、验收、清单和发布，分析器不下载安装其他分析器。这样每包均可独立使用，代价是
各消费者需要维护安装和调度能力；Narrant 已有这些能力，通用消费者可按发布契约接入。

分析请求接受一个项目根和可选文件列表。省略列表按项目配置发现源码，显式空列表返回空图；
显式选集只生成所选文件的完整节点。多个独立项目分别调用，不递归扩展图范围。

此决定替代 [ADR-0037](0037-extract-codegraph-behind-one-cli.md) 中必经总 CLI 与独立
CLI 发布物的部分。独立发布归属、固定版本、图差异留在 Narrant、应用发布身份均保持原决定。
完整范围见 [规范 0027](../specs/0027-independent-codegraph-project.md)。
